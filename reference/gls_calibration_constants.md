# Calibration constants for the GLS age calculator

Table 2 / calibration constants from the in-prep Np AAR calibration
study (n = 128 Neogloboquadrina pachyderma samples), reproduced from the
author's spreadsheet calculator's `Constants` sheet.

## Usage

``` r
gls_calibration_constants
```

## Format

A named list with elements `a_Asp`, `e_Asp`, `MSE_Asp`, `n_Asp`,
`xbar_Asp`, `Sxx_Asp`, `a_Glu`, `e_Glu`, `MSE_Glu`, `n_Glu`, `xbar_Glu`,
`Sxx_Glu`, `rho`, `SE_rho`, `t50`, `t66`, `t90`.
